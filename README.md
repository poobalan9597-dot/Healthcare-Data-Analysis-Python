# Healthcare-Data-Analysis-Python
Project Overview

This project focuses on analysing healthcare data using Python libraries to identify patient trends, medical conditions, admission patterns, and department-wise distributions.

Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Google Colab

Project Analysis

- Patient Data Analysis
- Gender-wise Patient Comparison
- Age Group Analysis
- Department-wise Patient Analysis
- Medical Condition Analysis
- Admission Type Analysis
- Urgent vs Emergency Comparison
- Monthly Healthcare Analysis
- Data Visualization using Matplotlib
- Subplots Dashboard

Dataset

Healthcare dataset containing 1000 patient records.

Objective

To analyse healthcare data, identify useful patterns, and generate insights through data visualization.
